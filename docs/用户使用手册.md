# 冰川区灾害链判识—评估—预警—断链综合防控系统

## 用户使用手册

---

## 一、文档说明

### 1.1 适用范围

本手册面向系统使用人员（业务人员、管理人员、成果审查人员），说明平台各项功能的作用、
输入数据要求、操作步骤与结果查看方式，覆盖资源目录、模型计算、监测预警、断链防控与数据管理全部功能。

### 1.2 阅读约定

| 约定 | 说明 |
| --- | --- |
| 功能名称 | 与界面左侧功能菜单名称一致 |
| 坐标 | 除特别说明外，经纬度均为十进制度（WGS84） |
| 栅格数据 | 支持的常见格式为 .tif / .tiff；部分功能兼容 .asc / .txt |
| 矢量数据 | 上传矢量时需同时选择 .shp / .dbf / .shx / .prj 等同名文件 |
| 时间单位 | 秒（s）、分钟（min）、小时（h），以各参数表标注为准 |
| 提示信息 | 界面弹出的提示框，用于告知运行进度、成功或失败原因 |

> 本手册只描述功能与操作方法，不涉及系统内部的实现细节。

## 二、系统概览

### 2.1 系统定位

系统面向冰川区灾害链的“判识—评估—预警—断链”全过程，提供从风险源识别、动力学模拟、
风险评估，到监测预警与断链调控的一体化作业环境，支持在三维地图上完成数据浏览、参数计算、
成果叠加与对比分析。

## 三、通用操作

### 3.1 地图浏览

| 操作 | 效果 |
| --- | --- |
| 按住鼠标左键拖动 | 平移地图 |
| 滚动鼠标滚轮 | 缩放地图 |
| 按住鼠标右键拖动 | 调整视角（俯仰与旋转） |
| 点击地图上的点要素 | 弹出该点的信息卡片或数据弹窗 |

系统在加载图层、输出计算结果与绘制调控范围后，会自动将镜头定位到目标区域，无需手动寻找。

### 3.2 工具条

| 工具 | 使用方法 |
| --- | --- |
| 测量距离 | 点击启用后，在地图上依次点击途经点，界面显示累计距离；测量完成后关闭该工具 |
| 测量面积 | 点击启用后，在地图上圈定闭合区域，界面显示区域面积 |
| 设置位置 | 输入经度、纬度后点击「确认」，在地图上落一个定位点；点击「取消」放弃 |
| 添加属性 | 打开属性录入表单，填写灾害点信息并提交，提交后在地图上生成对应点位 |
| 查询属性 | 打开属性查询面板，支持按区划或按属性检索，并支持在地图上点选查询 |
| 清除实体 | 一键清除地图上的临时要素与计算结果图层 |
| 全部灾害点 | 打开属性表，查看平台内全部点位（含自行新增的点位）并可按行删除 |
| 重置 | 恢复地图初始状态 |

### 3.3 资源目录的使用

- 勾选图层：图层加载到地图；取消勾选：图层从地图移除。
- 勾选上级目录会同时加载其下所有图层，取消勾选则一并移除。
- 加载“地形因子”下任一层后，右下角自动出现对应图例；加载模型结果后，自动出现该结果的图例。
- 图层数量较多时建议按需勾选，避免同时加载过多图层影响浏览流畅度。

### 3.4 计算结果的查看

1. 运行完成后，系统给出成功提示，并自动将结果作为图层加载到地图上。
2. 结果图层会自动定位到成果范围；若定位与预期不符，请检查输入数据的坐标系与覆盖范围。
3. 动力学类结果以逐帧方式循环播放，可直观查看运动与堆积过程；图例中给出该结果的色带与数值范围。
4. 需要重新分析时，可先使用「清除实体」移除上一次结果，再修改参数重新运行。

### 3.5 运行通用注意事项

- 带“必填/必选”标识的输入项未完成时，系统会逐项提示，无法启动计算。
- 计算耗时与数据范围、时间长度有关，运行期间请保持页面打开，进度会在提示信息中更新。
- 同一功能重复运行时，会覆盖上一次的结果图层。
- 上传数据建议使用同一空间范围与坐标系；坐标系不一致时，系统按各功能说明中的规则处理。

## 五、灾害链风险源判识

### 5.1 风险源定量识别与表征模型

**功能作用**：逐网格评估不同降雨历时下的坡体稳定性，识别不稳定区（滑坡、泥石流物源）的位置与规模，
输出各时段的不稳定区分布，为风险源判识、预警与防治规划提供依据。

**输入参数**

| 参数 | 单位 / 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 地点 | 文本 | 空（示例“林芝市”） | 本次计算的地点名称，用于成果记录与图层对应 |
| 色带 | 危险等级 / 灰度 / 红绿蓝 / 红色渐变 | 危险等级 | 成果出图配色；建议使用“危险等级”分级设色 |
| 预测时间 | 3h / 6h / 12h / 24h / 48h / 60h，可多选 | 不选 | 需要评估的降雨历时；勾选几个时段就输出几组成果，至少勾选一项 |
| 入渗率 | m/s | 1.0e-6 | 坡面入渗速率；值越大，土体饱和度上升越快、越易失稳 |
| 初始地下水位 | m | 3.0 | 计算初始时刻的地下水位埋深；埋深越浅越易失稳 |
| 土壤最大深度 | m | 2.4 | 参与计算的土层最大厚度，决定潜在滑面的搜索深度 |
| 水力扩散系数 | m²/s | 1.32e-3 | 孔隙水压力的扩散能力，越大则压力扰动传播越快 |
| 饱和渗透系数 | m/s | 1.32e-5 | 土体饱和后的渗透能力，与入渗率共同控制地下水位响应 |

**操作步骤**

1. 点击功能菜单中的「风险源定量识别与表征模型」。
2. 填写地点、选择色带。
3. 勾选需要评估的一个或多个预测时间。
4. 按需调整入渗率、初始地下水位、土壤最大深度、水力扩散系数、饱和渗透系数。
5. 点击「运行」，等待提示信息提示完成。

**结果说明**

- 按所勾选的时段逐个输出评估成果图层，数值越小越不稳定：0–1 为不稳定高风险区，1–10 为稳定区。
- 结果自动加载到地图，可转出为专题图用于汇报与归档。
- 勾选的时段越多，运行时间越长。

### 5.2 冰川泥石流易发性预测模型

**功能作用**：根据流域地形、地质、植被、降雨等因子，预测冰川泥石流易发程度，
输出带易发性概率与等级的结果图层，用于重点区筛选与隐患识别。

**输入数据**

| 输入项 | 格式 | 说明 |
| --- | --- | --- |
| Shapefile | .shp / .dbf / .shx / .prj | 必填。上传时需一次多选同名的一组文件；数据缺少坐标系信息时按 EPSG:32646 处理 |

**补值参数**（当上传数据缺少下列字段时，用此处填写的数值补齐；字段存在时以文件属性值为准）

| 参数 | 单位 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 坡向 | ° | 150 | 坡面朝向，影响日照与融冰差异 |
| 曲率 | — | 0.002 | 地形曲率，反映坡面汇流／发散与物质堆积条件 |
| 断层距离 | m | 30000 | 距最近断层的距离，表征构造破碎带影响 |
| NDVI | —（-1～1） | 0.001 | 植被覆盖指数，值越低越易发生侵蚀与启动 |
| 降雨量 | mm | 700 | 降雨驱动因子 |
| 起伏度 | m | 250 | 地形起伏幅度，控制势能与物质搬运能力 |

**建议的数据字段**（字段名受长度限制时可能为截断名）

| 建议字段 | 含义 | 建议字段 | 含义 |
| --- | --- | --- | --- |
| Aspect | 坡向 | Slope | 坡度 |
| Curvature | 曲率 | Soil thick | 土层厚度 |
| Fault dist | 断层距离 | SPI | 沟壑功率指数 |
| Glacier ar | 冰川面积比 | Stream Dis | 距河流距离 |
| Gully grad | 沟谷坡度 | Surface ro | 地表粗糙度 |
| NDVI | 植被覆盖指数 | Temperatur | 温度 |
| Precipitat | 降雨量 | TWI | 地形湿度指数 |
| Relief amp | 地形起伏度 | — | — |

**操作步骤**

1. 点击「冰川泥石流易发性预测模型」。
2. 选择并上传 Shapefile 同名文件组（至少包含 .shp）。
3. 按需填写 6 个补值参数。
4. 点击「上传并提交」，等待结果加载。

**结果说明**

- 结果图层按 5 个易发性等级分级设色（极高、高、中、低、极低），并附等级图例。
- 等级越高表示该区域越易发生冰川泥石流，可结合风险源判识成果确定重点排查区。

## 六、灾害链模拟

### 6.1 冰川泥石流动力学模型

**功能作用**：模拟冰川泥石流的启动与运动过程，输出逐时刻泥石流层厚度分布，
用于评估运动路径、堆积范围与致灾强度。

**输入数据**（三份栅格均需覆盖同一范围）

| 输入项 | 格式 | 说明 |
| --- | --- | --- |
| 平均高程 | .tif / .tiff | 必填。地形基准面，作为流动计算的底床 |
| 物源启动区 | .tif / .tiff | 必填。标记参与启动的物源分布范围，决定初始流体的位置与体积 |
| 影响范围 | .tif / .tiff | 必填。限定计算域，范围外的像元不参与演算 |

**操作步骤**

1. 点击「冰川泥石流动力学模型」。
2. 依次选择平均高程、物源启动区、影响范围三份栅格。
3. 点击「运行」，等待计算与渲染完成提示。

**结果说明**

- 结果为逐时刻泥石流层厚度，默认按层厚渲染并以逐帧方式循环播放。
- 结果自动定位到影响范围，并在右下角显示层厚图例与最大值。
- 本功能无可调物理参数，全部动力学参数按案例统一配置。

### 6.2 冰岩崩动力学模型

**功能作用**：模拟冰岩崩—泥石流耦合条件下的启动、输移与堆积过程，
输出逐时刻泥石流层厚度、水层厚度与流速，用于堰塞湖溃决—洪水—泥石流链式过程分析与风险评估。

**输入数据**

| 输入项 | 格式 | 默认 | 说明 |
| --- | --- | --- | --- |
| 数据坐标系 | EPSG 代码 | EPSG:32646 | 当输入为 .txt / .asc 且不带坐标信息时按此解释；.tif 以文件自身坐标为准 |
| 源区中心（经度 / 纬度） | 十进制度 | 95.0020 / 30.2354 | 当输入为 .txt / .asc 且缺少定位信息时，用于把结果落到地图上的实际位置 |
| 灾前地形（zb） | .tif/.tiff/.txt/.asc | 使用内置示例数据 | 泥石流发生前的地形，作为初始底床 |
| 灾后地形（zl） | .tif/.tiff/.txt/.asc | 使用内置示例数据 | 泥石流发生后的地形；泥石流层厚度为灾前与灾后地形之差 |
| 初始水深（hw） | .tif/.tiff/.txt/.asc | 使用内置示例数据 | 堰塞湖、河道等初始水体分布 |

> 上式三份数据要么都上传、要么都不上传，只上传其中一部分会被拦截。

**模型参数**

| 参数 | 单位 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 基底摩擦角 | rad | 0.05 | 有效基底摩擦角（弧度），数值越大阻力越强、运动越易停止 |
| 曼宁摩擦系数 | — | 0.0125 | 反映地表糙率，控制流速大小与下泄过程 |
| 网格长度 | m | 20 | 计算网格 x 方向尺寸，影响精度、稳定性与耗时 |
| 网格宽度 | m | 20 | 计算网格 y 方向尺寸 |
| 滑坡密度 | kg/m³ | 2700 | 固相（滑坡／泥石流）密度 |
| 河水密度 | kg/m³ | 1000 | 液相（水）密度 |
| 输出间距 | s | 10 | 结果输出时间间隔，越小结果越密、数据量越大 |
| 计算时间 | s | 200 | 模拟总时长，需覆盖完整的启动—输移—堆积过程 |

**操作步骤**

1. 点击「冰岩崩动力学模型」。
2. 按需填写数据坐标系与源区中心，并上传灾前地形、灾后地形、初始水深。
3. 填写模型参数（可直接沿用默认值）。
4. 点击「运行」，等待进度与完成提示。

**结果说明**

- 结果的渲染场固定为泥石流层厚度，逐帧循环播放并自动定位相机。
- 计算时间越长、网格越密，耗时越明显；模拟时间较长时系统会给出预计耗时提示，请保持页面打开。
- 若灾前与灾后地形完全相同，层厚为 0，此时只能看到水层，建议提供真实的灾前／灾后地形。

### 6.3 冰岩崩起动模型

**功能作用**：针对冰川区冰—岩组合边坡，按不同破坏模式计算冰岩崩的起动条件与启动规模，
输出源区稳定性判断与崩落量级，为下游泥石流物源与灾害链演进提供启动条件。

### 6.4 泥石流启动物源计算模型

**功能作用**：结合降雨、气温序列与冰川区含冰条件，计算流域尺度泥石流启动的物源量级与空间分布，
识别物源启动区与启动深度，为后续启动—输移—堆积模拟提供物源输入。

**输入参数**

| 参数 | 格式 / 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 降雨栅格路径 | .tif / .tiff，可多选 | 不选 | 多时相降雨量数据，用于入渗与产流计算；多选时按时间顺序排列 |
| 温度栅格路径 | .tif / .tiff，可多选 | 不选 | 与降雨数据时间序列对应的气温数据，用于融冰量计算 |
| 体积含冰量 | 0–1 | 0.2 | 冰川区冰体体积占比；含冰量越高，同等升温条件下的产流与物源量越大 |

> 当前版本降雨、温度栅格路径用于记录本次计算使用的数据；实际参与计算的主要可调参数为体积含冰量。

**操作步骤与结果**

1. 按需选择降雨、温度栅格（可多选），填写体积含冰量。
2. 点击「运行」，等待提示完成。
3. 结果为最后时段的物源启动深度分布，自动加载为图层并定位到成果范围，右下角显示 ZMAX 图例。
4. 计算结果可作为「冰川泥石流动力学模型」「冰岩崩动力学模型」的物源输入。

## 七、风险评估

### 7.1 全域风险脆弱性分析

**功能作用**：以 12 项孕灾环境因子为输入，叠加得到全域尺度的风险脆弱性分级结果，
用于识别高风险区、支撑防治规划与重点区筛选。

**输入参数（逐项导入栅格）**

| 因子 | 说明 |
| --- | --- |
| 平均高程 | 地形基准面，间接反映气温与冰川发育条件 |
| 地形起伏度 | 高差变化，控制势能与物质搬运能力 |
| 流域面积 | 汇水规模，影响径流与物源汇集 |
| 地层岩性 | 岩性分类，反映抗侵蚀能力 |
| 断层密度 | 构造活动强度与岩体破碎程度 |
| 土壤类型 | 土壤可蚀性差异 |
| 距水系距离 | 距水系越近，承灾暴露度越高 |
| 河网密度 | 汇流通道发育程度 |
| 降雨数据 | 降水驱动因子 |
| 土地利用 | 地表覆被与人类活动影响 |
| 距公路距离 | 道路承灾体可达性与暴露度 |
| NDVI | 植被覆盖度，影响水土保持能力 |

**操作步骤**

1. 点击「全域风险脆弱性分析」。
2. 逐项导入 12 个因子栅格（缺项会在提交时逐项提示因子名称）。
3. 点击「运行」，等待计算完成。

**结果说明**

- 结果为全域风险脆弱性分级图层，自动加载并定位到成果范围。
- 建议各因子使用同一空间范围与分辨率；如个别因子缺失，可先用同范围的近似数据替代。

## 八、监测预警

### 8.1 基于位移监测滑坡预警

**功能作用**：根据位移监测时序数据判断坡体是否进入加速变形阶段，估计失稳时间并分级给出预警。

**输入参数**

| 参数 | 格式 / 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 地点 | 文本 | 空（示例“林芝”） | 监测点名称，随结果写入平台，用于地图点位与查询 |
| 位移文件 | Excel（.xlsx），结构相同的 .csv 也可识别 | 必填 | 需包含两列：timestamp（时间，形如 2022-01-01 00:00）与 displ（位移数值） |
| 经度 | 十进制度 | 空 | 预警点在地图上的经度，缺失将无法定位结果点 |
| 纬度 | 十进制度 | 空 | 预警点在地图上的纬度 |

**操作步骤**

1. 点击「基于位移监测滑坡预警」。
2. 选择位移文件，填写地点与经度、纬度。
3. 点击「运行」，等待结果返回。

**结果说明**

| 剩余时间 | 预警颜色 |
| --- | --- |
| 小于 24 h | 红色 |
| 24–48 h | 橙色 |
| 48–72 h | 黄色 |
| 72–96 h | 蓝色 |
| 超过 96 h | 提示“预计失稳时间超过 96 小时” |

- 系统在指定经纬度位置落下预警图标并自动定位；点击预警点可查看该监测点的位移数据。
- 若提示“暂无法计算失稳时间”，说明监测序列中尚未出现明显的加速变形，建议补充更长的监测数据后重新运行。

### 8.2 冰川泥石流监测预警模型

**功能作用**：处理监测传感器采集的振动／地声时序信号，识别泥石流事件并在地图上展示事件位置。

**模式与输入文件**

| 模式 | 输入文件 | 适用情形 |
| --- | --- | --- |
| 模式一 | Excel（.xlsx） | 按表格采集的波形数据，默认读取第 1 列作为信号数值 |
| 模式二 | CSV（.csv） | 按列组织的电压／振动信号数据 |

**模式一参数**

| 参数 | 单位 | 默认值 | 说明 |
| --- | --- | --- | --- |
| Excel 文件 | .xlsx | 必填 | 传感器波形数据 |
| 经度 | 十进制度 | 97.5 | 事件在地图上的经度 |
| 纬度 | 十进制度 | 31.0 | 事件在地图上的纬度 |
| 阈值 | — | 2.5 | 事件触发阈值，调低更灵敏、易误报，调高更严格 |
| 短时窗 | s | 30 | 反映信号的瞬时变化 |
| 长时窗 | s | 240 | 反映背景噪声水平 |
| 分段时长 | s | 10 | 触发后把后续时间窗切分的片段长度 |
| 总时长 | s | 60 | 触发后向后检查的总时间长度 |
| 采样率 | Hz | 100 | 必须与硬件采集参数一致，否则时间窗换算不正确 |

**模式二参数**

| 参数 | 格式 | 默认值 | 说明 |
| --- | --- | --- | --- |
| CSV 数据文件 | .csv | 必填 | 按列组织的信号数据 |
| 经度 | 十进制度 | 97.5 | 事件点位经度 |
| 纬度 | 十进制度 | 31.0 | 事件点位纬度 |

**操作步骤与结果**

1. 点击「冰川泥石流监测预警模型」。
2. 按数据格式选择对应模式。
3. 上传数据文件，填写经度、纬度；模式一按需调整阈值与各时间窗参数。
4. 点击「运行」，系统返回检测结论并在指定经纬度落下事件点，点击可查看结果详情。

### 8.3 气象站数据查询

## 九、断链防控

> 两项调控技术用于评估工程调控措施的效果：在三维地图上手绘调控范围，
> 将范围内地形抬高指定高度后重新计算，与未调控工况对比即可评估削峰、减蚀效果。
> 断链调控基于「冰岩崩动力学模型」计算，沿程调控基于「冰川泥石流动力学模型」计算。

### 9.1 灾害链断链调控技术

| 项目 | 说明 |
| --- | --- |
| 适用场景 | 在物源启动—沟道输移的关键转换链节布设拦挡坝体，截断物源向下游的逐级放大 |
| 拦挡范围 | 在地图上手绘的闭合多边形，左键逐点落点、右键结束，至少 3 个顶点 |
| 坝体加高值 | m，默认 20 |
| 底床与水深数据 | 沿用「冰岩崩动力学模型」的输入数据；未选择文件时使用内置示例数据 |
| 动力学参数 | 基底摩擦角、曼宁摩擦系数、网格长宽、滑坡与河水密度、输出间距、计算时间沿用冰岩崩动力学模型默认值 |

**操作步骤**

1. 点击「灾害链断链调控技术」。
2. 点击「在地图上绘制」，沿目标沟道绘制闭合范围（左键落点、右键结束、Esc 取消）。
3. 填写坝体加高值，点击「执行断链调控计算」。
4. 计算完成后结果图层自动加载，与未调控工况的成果对比查看。

**注意事项**

- 绘制范围应落在输入数据覆盖范围内；范围过小或偏离沟道会明显削弱调控效果。
- 点击「清除绘制」可重新绘制范围。

### 9.2 冰川泥石流沿程调控技术

| 项目 | 说明 |
| --- | --- |
| 适用场景 | 沿泥石流运动路径布设护底与消能措施，抬升床面削弱沿程侵蚀冲刷，控制规模持续放大 |
| 调控范围 | 在地图上手绘的闭合多边形 |
| 床面抬升高度 | m，默认 15 |
| 输入栅格 | 沿用「冰川泥石流动力学模型」的三份输入数据（平均高程／物源启动区／影响范围），三份都需就绪 |
| 动力学参数 | 摩擦参数、模拟时长与滑移路径沿用冰川泥石流动力学模型默认配置 |

**操作步骤**：与 9.1 基本相同，区别在于调控范围沿沟道纵向布设；计算前需先准备好上述三份输入栅格（可在「冰川泥石流动力学模型」弹窗中上传并复用）。后端对高程栅格抬升后重新执行冰川泥石流动力学计算。

## 十、数据与属性管理

### 10.1 添加属性（新增灾害点）

1. 点击工具条中的「添加属性」。
2. 填写下列信息（名称与潜在滑坡体积规模为主要识别信息）：

| 字段 | 说明 |
| --- | --- |
| 名称 | 点位名称 |

**查询方式二：属性查询**

1. 在「属性查询」中选择查询字段（地点 / 坡度 / 规模）并填写条件值。
2. 点击「查询」：左键查询灾害点，中键（滚轮键）点击可查询气象站。

**其他操作**

| 按钮 / 操作 | 说明 |
| --- | --- |

| 清空查询条件 | 重置当前查询条件 |

### 10.3 清除与重置

- 「清除实体」：清除地图上的临时要素与模型计算结果图层（含逐帧播放的成果）。
- 「重置」：恢复地图初始状态。
- 通过资源目录逐项取消勾选，可精确移除某一个图层。

## 十一、常见问题与处理建议

| 现象 | 可能原因与处理建议 |
| --- | --- |
| 点击「运行」后提示缺少输入项 | 按提示逐项补齐必填数据；矢量数据需一次多选同名文件组 |
| 计算结果图层未出现 | 确认提示信息中是否给出错误原因；必要时先「清除实体」再重新运行 |
| 结果位置与预期不符 | 检查输入数据的坐标系与覆盖范围，或在无坐标信息的格式下补充数据坐标系与源区中心 |
| 运行时间很长 | 计算耗时可随范围、网格密度与模拟时长增加而明显增长；请保持页面打开，必要时减小计算时间后重试 |
| 结果看不到厚度分布 | 若灾前与灾后地形相同，层厚为 0；请确认输入地形为真实灾前／灾后数据 |
| 气象站弹窗表格为空 | 该站点近期暂无入库记录，可稍后重新打开查看 |
| 地震动设备无数据 | 确认设备图层已加载、设备在线并已产生监测记录 |
| 图层过多导致浏览卡顿 | 在资源目录中取消不需要的图层后再查看目标成果 |
